South Bangla Group website
==========================
Open index.html in any browser. No installation needed.

Edit content:   js/data.js  (company text, leaders, contacts, photo lists, group phone/email)
Edit design:    css/style.css  (colours are the variables at the top)
Photos/logos:   assets/img/

To publish: upload the whole "site" folder to any web host (Netlify, Vercel, cPanel, GitHub Pages).
